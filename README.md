### 📝 Smart Task Manager (CLI)

A simple command-line task manager built using Python.

**Features:**

* Add new tasks
* View all tasks
* Mark tasks as completed
* Delete tasks
* Track productivity stats
* Saves data using JSON file storage

**Tech Used:**

* Python 🐍
* File handling (JSON)
* CLI-based interface

**How to run:**

```bash
cd projects/smart-task-manager
python main.py
```
