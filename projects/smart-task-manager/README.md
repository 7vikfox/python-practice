# 🧠 Smart Task Manager (CLI)

A lightweight Python command-line task manager that helps you organize daily tasks efficiently.


## 🚀 Features

- Add new tasks
- Mark tasks as completed
- Delete tasks
- View all tasks
- Track productivity stats
- Persistent storage using JSON


## 📦 Installation

git clone https://github.com/7vikfox/python-practice.git
cd python-practice/projects/smart-task-manager
python main.py
